# Understanding XenFlo

How I learned this codebase well enough to explain every file.

| File | What it is |
|---|---|
| [xenflo-study-guide.pdf](xenflo-study-guide.pdf) | A 93-page study guide in 12 chapters (dark theme), from pasting a URL to saving a knowledge base. Each chapter has diagrams, the real code with file and line references, "why it's built this way" notes, and check-yourself questions with answers. |
| [my-notes.pdf](my-notes.pdf) | My handwritten notes on the study guide. It's **one large board** on a single page, so zoom in to read it. |

## Suggested reading order

1. **00–02:** the map, the tech stack and the data model. Start here.
2. **03–04:** the scrape flow (robots.txt, crawl ranking, Dig deeper, SSRF) and the extractors.
3. **05–06:** AI enrichment (the guards, the route deadline, preview mode) and menus.
4. **07–09:** the UI, saving and versions, and testing and deploying.
5. **10 and 11** are reference: the glossary, and a ranked list of things to simplify later.

Read a chapter in the guide first, then the matching part of my notes. The notes show what I found hard and how I put it in my own words.
